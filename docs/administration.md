# Администрирование и мониторинг

Одна установка шлюза соответствует одному учреждению. Панель доступна по `/admin/` на адресе шлюза. Учётная запись создаётся один раз по коду первоначальной настройки из защищённого окружения сервера.

## Настройки

- «Учреждение»: название, логотип PNG/WebP до 300 КБ, основной цвет, фон, контакты, текст помощи, языки и крупный шрифт. Включены нейтральная тема и две синтетические темы.
- «Получение результатов»: способы входа, PDF-предпросмотр, печать и таймеры. Доступные на терминале способы ограничены capabilities МИС. Язык по умолчанию должен входить в список включённых языков.
- «Подключение МИС»: HTTPS URL без userinfo/query, ключ, доверенный CA PEM, таймаут. Пустое поле ключа сохраняет предыдущий ключ. Проверка подключения использует сохранённые настройки.
- «Терминалы»: создайте одноразовый код на 10 минут, зарегистрируйте приложение и настройте оборудование и индивидуальные таймеры сеанса. Отзыв отключает API-доступ и завершает активные сессии.
- «Импорт и экспорт»: переносит общую публичную конфигурацию. Учётные данные и индивидуальные настройки оборудования не экспортируются.

Конфигурация публикуется целиком с возрастающим номером версии. Одновременное сохранение устаревшей версии отклоняется. Терминал проверяет обновления каждые 30 секунд на стартовом экране и применяет их до следующего пациента.

## Оборудование

Принтер задаётся точным системным именем. На Windows установите SumatraPDF и укажите путь к `SumatraPDF.exe`, если он не находится в стандартном Program Files. Приложение запускает только этот helper с фиксированными аргументами, без shell. На Linux установите и настройте CUPS и `cups-client`. Состояние очереди не гарантирует физическую выдачу всех страниц.

Сканер: HID-клавиатура либо COM/USB-serial. Для serial задайте стабильный путь порта и baud rate; Linux предпочтительно `/dev/serial/by-id/...`. Шаблон токена проверяется Rust regex; исходные сканы не журналируются. Парсер PDF417 полиса перенесён из исходного проекта. Для HID ввод направляется в активное поле; при завершении скана Enter подтверждает форму.

## Мониторинг

Нативное приложение опрашивает устройство примерно каждые 15 секунд; heartbeat отправляет последний снимок шлюзу каждые 30 секунд. Панель обновляет список каждые 15 секунд.

- Терминал: последний heartbeat, версия приложения, ОС, uptime, CPU, использованная/общая RAM, свободное место на диске конфигурации.
- COM-сканер: открытие порта и сохранение соединения.
- HID-сканер: наличие настроенного PNPDeviceID на Windows или `/dev/input/by-id/...` на Linux. Без идентификатора — `HID_UNVERIFIED`, а не ложное состояние «Готов».
- Принтер Windows: WMI-состояние драйвера/очереди, offline, известные ошибки бумаги/тонера. Linux: CUPS `lpstat`, состояние очереди.

Состояния: «Готов», «Занят», «Ошибка», «Нет соединения», «Не проверено». При возрасте heartbeat или аппаратного снимка более 90 секунд панель показывает отсутствие свежих данных. Неизвестное состояние драйвера не превращается в «Готов». `ready` подтверждает доступность на уровне ОС; функциональная проверка сканирования и печати проводится на стенде.

В browser demo нативных метрик нет; поля мониторинга остаются непроверенными. Возможность тестовой физической печати из админ-панели не предусмотрена: она не должна неожиданно запускать аппаратные действия.
