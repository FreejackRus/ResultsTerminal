# Модель безопасности

Границы доверия: пациент → UI; UI → ограниченный Tauri IPC; терминал → HTTPS-шлюз; администратор → панель; шлюз → HTTPS-МИС; печать → системный драйвер.

- Ключ МИС находится только на шлюзе, шифруется AES-256-GCM. Ключ шифрования — отдельный файл рядом с SQLite; резервная копия должна включать оба файла и храниться защищённо.
- Пароли администраторов хешируются scrypt с индивидуальной солью. Cookie: HttpOnly, SameSite=Strict, Secure в production. Изменения требуют нестандартного anti-CSRF заголовка; CORS не открыт.
- Одноразовые enrollment-коды и ключи терминалов в SQLite хранятся как SHA-256. Доступ отзывается немедленно. Токен терминала хранится в app_config_dir нативного приложения и не возвращается renderer.
- Production launcher требует TLS certificate/key и не содержит выключателя проверки TLS. Исключение HTTP — только loopback локального режима разработки. Ключи и секреты не помещаются в VITE-переменные.
- JSON проверяется схемами, SQL параметризован, произвольные shell-команды не принимаются. МИС не может направить терминал на сторонний URL или сетевую папку.
- Настройки и журналы не содержат медицинских документов. Сессии временные, ограничены терминалом; поздние ответы после reset отклоняются. При рестарте шлюза все его сессии становятся недействительными.
- PDF проверяется по Content-Type, сигнатуре и размеру. Процесс просмотра ограничен CSP и локальным worker. Обновления PDF-движка и системного WebView входят в обслуживание учреждения.
- Временная папка печати принадлежит приложению; файлы удаляются после операции и при следующем запуске. Журнал идентификаторов заданий записывается до запуска spooler: после сбоя неизвестное задание автоматически не повторяется.
- Linux-каталог приложения — 0700, файлы с секретами — 0600. На Windows используйте отдельную ограниченную учётную запись киоска и ACL пользовательского профиля. ОС и драйверы входят в доверенную среду.

Установка приложения не сертифицирует инфраструктуру учреждения. Резервное копирование, доверенные сертификаты, политики входа и доступ к системным устройствам настраиваются при внедрении. Настройки защищённости Astra не понижаются приложением.
