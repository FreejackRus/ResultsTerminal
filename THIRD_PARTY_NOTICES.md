# Происхождение и сторонние компоненты

Новый продукт создан на базе требований владельца. Самостоятельный Rust crate `oms_parser` перенесён из https://github.com/BogusKladik/result-terminal.git, commit `7d46ac718cfe7fe328dc8d5e7168c1af27613085`, файл `src-tauri/crates/oms_parser/src/lib.rs`. История исходного проекта не импортируется. Исходный репозиторий не содержал файла LICENSE на этом commit; права на распространение перенесённого кода должны быть урегулированы владельцем перед внешней поставкой. Этот документ не назначает лицензию чужому коду.

Алгоритм остановки печатной очереди при неопределённой отправке воспроизведён по поведению `src/shared/service/printBatch.ts` того же проекта. Привязанные к учреждению ресурсы, просмотрщики и бинарники не переносились.

Используемые открытые компоненты включают React (MIT), Vite (MIT), Fastify (MIT), TypeBox (MIT), Ajv (MIT), Undici (MIT), Tauri (MIT/Apache-2.0), PDF.js (Apache-2.0), pdf-lib (MIT), IBM Plex Sans (SIL Open Font License). Точные версии фиксируются в pnpm-lock.yaml и Cargo.lock; оригинальные LICENSE остаются в пакетах зависимостей. При поставке должны сохраняться применимые notices этих зависимостей.

SumatraPDF не включён в репозиторий или установщик. Его устанавливает учреждение отдельно из официального дистрибутива в соответствии с его лицензией. Приложение использует установленный исполняемый файл для печати. Linux использует установленную системную подсистему CUPS.
